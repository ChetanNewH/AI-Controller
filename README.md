# AI-Controller
This AI Gesture Controller leverages OpenCV and MediaPipe to enable touchless system interaction. Using real-time hand landmark detection, it translates finger distances into hardware commands. Users can toggle control modes to adjust Volume via PyCaw or Brightness via SBC, bridging the gap between computer vision and daily utility.
